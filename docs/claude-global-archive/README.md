# Claude global asset archive

Point-in-time copies of global Claude Code assets (`~/.claude/`) that this project relies on. `~/.claude/` is not a git repo, so these files have no version history of their own — this folder is that history.

**These are copies, not the live source.** Editing a file here does nothing; the actual asset lives under `~/.claude/skills/`, `~/.claude/commands/`, or `~/.claude/scheduled-tasks/`. Re-copy here after any change, in the same commit as the DECISIONS.md/LEARNINGS.md entry.
